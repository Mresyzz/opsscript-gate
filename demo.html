# opsscript-gate v0.8.1
GitHub Interactive Demo 5-Line CI
POSIX Syntax Linters vs Container Runtime Reality

ShellCheck tells you if your script looks portable.
OpsScript Gate checks if it actually runs there.

静态检查器（ShellCheck）验证引用完整性与 AST 语法规则。但它无法感知最小化镜像中是否存在 apt-get、/bin/bash 或特定的包管理命令。 OpsScript Gate 在只读隔离的 Docker 矩阵（Debian、Ubuntu、Alpine）中真实预演脚本，在 CI 中抓出崩溃。

💡 智能修复建议 (Automated Remediation Hint)

检测到脚本在 Alpine 镜像下调用了 apt-get。Alpine 默认使用 apk 作为包管理器。

# 建议的跨平台包管理分支写法：
if command -v apt-get >/dev/null 2>&1; then apt-get update && apt-get install -y curl;
elif command -v apk >/dev/null 2>&1; then apk add --no-cache curl; fi

5 行代码无感接入 GitHub Actions

无需注册账号、无需 API Key、零第三方云端依赖。在 GitHub Actions 官方 Runner 上纯本地 Docker 运行。

.github/workflows/compatibility.yml 
name: Script Runtime Compatibility
on: [push, pull_request]

jobs:
  compat:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run OpsScript Gate
        uses: Mresyzz/opsscript-gate@v0.8.1
        with:
          script-path: ./install.sh
          shell: auto
