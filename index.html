Workflow Definition

Executes locally within the runner Docker daemon without tokens, external webhooks, or account setup.

.github/workflows/gate.yml • 15 lines 
# OpsScript Gate - Cross-distribution runtime verification
name: Script Runtime Compatibility
on: [push, pull_request]

jobs:
  compatibility:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Validate scripts across distributions
        uses: Mresyzz/opsscript-gate@v0.8.0
        with:
          script-path: ./install.sh
          shell: auto
          timeout-seconds: 120
